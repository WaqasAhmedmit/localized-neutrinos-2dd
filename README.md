# Localized Neutrinos in Two Dark Dimensions

This repository contains the numerical codes and Jupyter notebooks used for the study of localized sterile neutrinos in a six-dimensional framework with two compact dark dimensions.

The model localizes gauge-singlet right-handed neutrinos near the Standard-Model brane. The brane-visible sterile excitations form shells with

$$
M_s^2 = 8\mu^2 s,
$$

and the leading active–sterile mixing behaves as

$$
\theta_{is}^2 \simeq \frac{m_i^2}{8\mu^2 s}.
$$

The notebooks reproduce the main numerical results and figures of the manuscript, including:

- Dirac neutrino masses and Yukawa couplings
- 2DD compactification-radius relations
- Localized sterile-shell spectrum
- Active–sterile mixing
- Reactor neutrino survival probabilities
- Tritium beta-decay spectral distortions
